# Documentation

User documentation for LTEM:

- [Writing LTEM tables](guide.md): the notation, step by step, with examples, how tables look in renderers without LTEM support such as GitHub, and prompts for using LTEM with LLMs
- [LTEM and other merged-cell table syntaxes](comparison.md): one table in MultiMarkdown style, grid tables and HTML, and why LTEM writes it the way it does
