# Changelog

Version 1.0 of the specification, the table model ([`../ast/`](../ast/)) and the conformance tests ([`../conformance/`](../conformance/)) is frozen. Later versions 1.0.x only correct errors. A change to the syntax needs a new version.

## 1.0 (2026-10-14)

The first version. It covers merged cells (`<<`, `^^`, `{c:N}`, `{r:M}`), several header rows and line breaks in cells. It follows the paper *LTEM: LLM-Friendly Table-Enhanced Markdown for Table Understanding and Generation* (EMNLP 2026); [Appendix A](ltem-spec.md#appendix-a-relation-to-the-paper) lists the differences and additions.
